# 🧮 Scientific Calculator – Java Swing Application

A feature-rich **Scientific Calculator** built using **Java Swing**. This desktop application supports both basic arithmetic operations and advanced scientific functions, presented in a modern, user-friendly graphical interface.

---

## 🛠️ Technologies Used

- **Java (JDK 8+)**
- **Swing** for GUI components
- **AWT** for event handling
- **Math Library** for scientific operations

---

## ✨ Features

- **Basic Operations**: `+`, `-`, `×`, `÷`
- **Scientific Functions**:
  - Trigonometric: `sin`, `cos`, `tan` (in degrees)
  - Logarithmic: `log`, `ln`
  - Power and roots: `xʸ`, `√`
  - Constants: `π`, `e`
  - Factorial: `n!`
- **Others**:
  - Clear (`C`) and Delete (`DEL`)
  - Decimal input support
  - Parentheses handling
  - Formatted output
